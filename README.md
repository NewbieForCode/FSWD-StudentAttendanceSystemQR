A Mock Student Attendance System based on students scanning QR codes to confirm attendance.

Expected features:
- Basic Login/Registering system for Students, Teachers and Admins.
- Student Details with CRUD + Searching
- Teacher Details with CRUD
- Course Records with CRUD + Filtering by IDs
- Course Sessions with CRUD
- External API for QR Generation (https://goqr.me/)

Created with ASP.NET Web API and ASP.NET Web Core MVC. 
Project started on September 29th 2026.
This is a student project made for academic purposes.
